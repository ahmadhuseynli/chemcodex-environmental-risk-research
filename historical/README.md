# Historical public prototype

The earlier **KnowYourHazards** Streamlit repository is preserved separately:

https://github.com/ahmadhuseynli/knowyourhazards

It is useful evidence of the project's transition from spreadsheet logic into a web application.

It should not be treated as the current regulatory/scientific specification. Some of its ranking and exemption logic was later found to be too simplified.

The current repository therefore links to it rather than copying the older rules into the new public engine.
