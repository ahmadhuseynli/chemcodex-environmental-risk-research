# Synthetic example

The JSON file in this folder is invented for demonstration.

It is not an SDS, not a real chemical case and not a regulatory benchmark.

Its purpose is only to show how the public parser and screening calculation connect:

**text evidence -> structured endpoint candidates -> explicit scenario inputs -> PEC/PNEC -> RQ**

A real assessment would require validated source data, an appropriate effect endpoint, justified assessment factor, scenario-specific exposure assumptions and the applicable regulatory framework.
